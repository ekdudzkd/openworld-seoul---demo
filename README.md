# 도트 서울 (프론트엔드 전용 프로토타입)

> 도트 아일랜드의 그래픽·캐릭터·움직임을 그대로 두고, 기본 맵을 **실제 서울 모양**으로 바꾼 버전입니다.

그린 그림이 그대로 3D 캐릭터가 되어 섬을 돌아다니고, 섬 안의 장소에서 미니게임에 들어가는 오픈월드 프로토타입입니다.
백엔드 없이 브라우저만으로 동작하며, 진행 상황은 `localStorage`에 저장됩니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성 (아무 정적 호스팅에 올리면 됨)
```

## 서울 맵

- **모양·비율**: 통계청 2013 행정구역 경계(25개 구)를 264×220 타일로 래스터화. 1타일 ≈ 147m, 서울 동서 끝(252타일)을 걸어서(4.2/s) **약 1분**.
- **한강**: 강북·강남 구 경계를 따라 생성, 13개 한강 다리로 건넘. 중랑천·청계천·안양천·탄천·양재천·불광천·샛강, 여의도·노들섬·밤섬.
- **길**: 강남구·서초구와 잠실(송파구 북쪽)만 바둑판 도로(아스팔트+골목), 나머지 지역은 한강 남북 모두 구불구불한 흙길(최소신장트리+골목). 범위는 `seoulMap.js`의 `markGrid()` / `GRID_SONGPA_Z`
- **나무**: 숲(예전 산 자리)·공원은 울창하게, 그 밖엔 넓은 길가 가로수 위주. 건물 바로 옆과 빽빽한 동네엔 거의 안 심음 (`world.js` `scatter()`). 표지판·미니게임 입구·역·선착장 주변 3.5칸과 시작 지점(광화문광장) 둘레 10칸은 시야를 위해 비움 (`finishTrees()`)
- **산 없음**: 북한산·관악산 등 산 자리는 평지 숲으로.
- **구별 랜드마크**: 경복궁·광화문광장·남산타워·숭례문·DDP·흥인지문·국립중앙박물관·서울숲·어린이대공원·경동시장·장미터널·고려대·4·19묘지·창포원·화랑대 철도공원·은평한옥마을·독립문·월드컵경기장·김포공항·목동·고척돔·가산디지털단지·국회의사당·63빌딩·노량진수산시장·서울대·예술의전당·코엑스·봉은사·강남역·롯데월드타워·석촌호수·올림픽공원·암사동 유적 (안내판에서 E로 설명)
- **미니게임 위치**: 과일 받기=경동시장, 닭 몰이=암사동, 벌레 잡기=노들섬 텃밭, 낚시=노량진 앞 한강 부두, 달리기=여의도 한강공원, 3:3 축구=월드컵경기장 한가운데, 오리배 레이스=성동구 한강공원 선착장(성수대교 서쪽), 자물쇠 찾기=남산타워 자물쇠 울타리 앞, 캐치볼=고척스카이돔 입구, 동물 먹이 주기=어린이대공원 먹이 판매대, 카트 레이싱=도봉운전면허시험장(노원구), 리듬게임=홍대 코인노래방, 길 안내 도우미=명동 관광안내소, 퍼레이드=이태원 지구촌 축제 무대
- **지하철 2호선**: 시청·왕십리·잠실·강남·신도림·홍대입구역 입구(초록 지붕)에서 E → 노선도에서 역을 누르거나 숫자키 → 터널 화면 후 도착역 출구로 이동. 노선도에서 한 칸마다 게임 시간 10분이 더 흐름 (`src/subway.js`)
- **한강 수상택시**: 강서·이촌·반포·뚝섬·강동 선착장(파란 안내판, 나무 데크)에서 E로 타고 WASD(카메라 기준)로 직접 운전, Shift 가속. 한강·하천으로 다닐 수 있고, 아무 선착장 앞에서 E로 내림. 한강 다리는 물 위 1.7 높이(양끝 비탈)라 걸어서 오르내리고, 배는 교각 사이로 다리 밑을 지나감 (끝쪽 낮은 곳·교각은 막힘, 밑을 지날 땐 상판이 도트 무늬로 투과). 지도엔 파란 네모 (`src/watertaxi.js`)
- **하루의 흐름**: HUD 시계(실제 7초 = 게임 10분, 하루 약 17분)에 맞춰 하늘·햇빛·안개 색이 바뀜. 새벽(보라) → 해돋이(주황) → 낮 → 황금빛 오후 → 노을 → 해질녘 → 밤(별·달, 건물 창문에 불, 넓은 길가 가로등 켜짐). `src/daynight.js`의 `KEYS` 표에서 시간대별 색을 고칠 수 있음. 시점을 아래로 드래그하면 하늘이 보임
- HUD에 현재 구 이름, 오른쪽 위 미니맵(M 또는 클릭으로 크게, 마우스 휠로 확대·축소, 큰 지도는 드래그로 이동). 캐릭터를 가리는 건물·나무는 도트 무늬로 투과.
- 맵 데이터 재생성: `tools/raster.py` (GeoJSON: southkorea/seoul-maps `seoul_municipalities_geo.json`을 tools/에 두고 실행)

## 흐름

1. **캐릭터 꾸미기** – 마인크래프트 스킨처럼 정해진 입체 틀(머리 10×10×10, 몸 8×7×5, 팔 3×7×3, 다리 4×5×4)의 각 면에 색을 칠함.
   - 3D 모델을 직접 클릭해서 칠하기 + 오른쪽 '면 확대 편집'에서 세밀하게 칠하기
   - 펜 / 면 채우기 / 부위 통칠 / 스포이드 / 좌우 대칭(기본 켜짐) / 되돌리기, 예시 스킨 2종, '걸어보기'로 움직임 확인
2. **월드 미리보기** – 섬 광장에서 손 흔들기·걷기·점프를 번갈아 보여줌 → `월드 입장`.
3. **월드** – WASD 이동(카메라 기준, 이동 방향으로 몸을 돌림), Shift 달리기, Space 점프, E 상호작용, 마우스 드래그로 시점 회전, 휠 줌, R 시점 초기화, Esc 다시 꾸미기.
   - 고양이 NPC(냥촌장), 표지판, 집, 닭, 나비, 연못
   - 노란 마름모가 떠 있는 곳에서 E를 누르면 미니게임 입장 (점수만큼 골드 획득, 게임별 최고 기록 저장)
4. **미니게임 14종** (`src/minigames/`) — 우상단 `✕ 나가기`(Esc)로 언제든 나갈 수 있음 (그 판 보상은 없음)

## 구조

```
src/
  main.js       화면 전환(state machine), 입력, 카메라, HUD, 저장
  editor.js     3D 스킨 에디터 (레이캐스트로 모델에 칠하기, 면 확대 편집, 대칭)
  character.js  입체 틀 정의, 스킨 데이터/예시, Avatar(관절 애니메이션: 걷기·달리기·점프·손 흔들기)
  world.js      월드 조립(지형 조각 텍스처, 물, 충돌 공간해시), NPC·동물, 미니맵, 상호작용 지점
  seoulData.js  서울 구 경계 타일 데이터 (자동 생성)
  seoulMap.js   타일맵 생성: 한강·하천·다리·강남 격자·강북 길·숲·랜드마크 배치
  city.js       건물(합친 지오메트리)·나무(인스턴싱)·다리, 시야 투과 셰이더
  landmarks.js  구별 랜드마크 모델
  minigames/    base.js(공통: 카운트다운·제한시간·하트·HUD·결과) + 게임별 파일, index.js(등록)
  textures.js   캔버스로 그린 16px 도트 텍스처 (잔디/모래/길/물/나무판/지붕/표지판)
  sfx.js        WebAudio 8비트 효과음
  fonts/        Galmuri11 픽셀 폰트 (SIL OFL)
```

### 도트 느낌을 내는 방법
- 렌더러를 화면의 1/3 해상도로 그린 뒤 `image-rendering: pixelated`로 확대 (`main.js`의 `PIX`).
- 모든 텍스처는 `NearestFilter`의 16px 타일.

### 미니게임 추가하는 법
1. `src/minigames/`에 `MiniGame`을 상속한 클래스를 만든다. `static meta`(id, title, hint, duration, hearts)와 `build()`, `reset()`, `step(dt, t, keys)`, `idle(dt, t)`, `resultRows()`만 채우면 된다.
2. `src/minigames/index.js`의 `GAMES`에 등록한다.
3. `world.js`에서 `this.addMarker(x, y, z)`와 `this.interactables.push({ x, z, r, label, kind: 'minigame', game: 'id', ret: [돌아올 x, z] })`로 입구를 만든다.
